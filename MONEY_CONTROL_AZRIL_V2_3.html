Cara Kerja Jadwal

Transaksi berulang diproses saat MONEY CONTROL dibuka. Jadwal yang sudah jatuh tempo akan dibuat satu kali per tanggal kejadian.

Frekuensi tersedia: mingguan, bulanan, dan tahunan. Untuk jadwal tanggal 29–31, aplikasi menyesuaikan ke hari terakhir bulan jika bulan tersebut lebih pendek.

Aplikasi tidak berjalan di latar belakang saat browser ditutup. Jika aplikasi lama tidak dibuka, tanggal yang terlewat akan diproses saat aplikasi dibuka kembali.

Menghapus jadwal tidak menghapus transaksi yang sudah tercatat dari jadwal tersebut.

System & Data Security

Kelola backup dan perlindungan data lokal.

Data Management

Data disimpan di browser perangkat ini. Ekspor backup secara rutin.

File backup berisi data keuanganmu. Simpan di lokasi pribadi yang aman. Jangan kirimkan ke orang lain jika tidak diperlukan.

Privacy & Security

Aplikasi ini tidak meminta akses rekening atau menyimpan PIN bank. LocalStorage tidak terenkripsi dan dapat diakses oleh pengguna browser/perangkat yang sama.

Gunakan kunci layar perangkat dan jangan memakai perangkat publik untuk data keuangan pribadi.

Mode offline tersedia setelah halaman termuat, tetapi sinkronisasi antarperangkat belum tersedia. Jadwal berulang hanya diproses saat aplikasi dibuka, bukan saat browser tertutup.
